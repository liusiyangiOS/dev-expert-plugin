## 如何复跑

仓库根目录，POSIX 用 `python3`，Windows PowerShell 可用已核验的 `py -3` 替换：

```bash
python3 -X utf8 -m unittest discover -s tests -p 'test_*.py' -v
python3 -X utf8 -m unittest discover -s packages/codex/skills/_shared -p 'test_expert_models.py' -v
python3 -X utf8 tests/audit_paths.py
python3 -X utf8 tests/audit_paths.py --installed
python3 -X utf8 tests/host_smoke.py
python3 -X utf8 tests/host_smoke.py --platform codex --codex-wire
git diff --check
```

前四条只用 Python 标准库。`--installed` 是可选的本机只读审计，不访问认证文件。宿主测试需要对应 CLI；Windows 测试器要求原生 `.exe`，缺少时明确报未运行，不将包装器参数未经检查地交给 shell。该限制仅属于测试器，专家团运行方式见各端 README。

宿主测试使用空目录与精简环境，不连接个人 app-server、不复制登录文件。`--codex-wire` 只监听 `127.0.0.1`，接收宿主产生的工具定义并返回预设拒绝响应，用于核验角色注册。它不完成模型推理、不调用外部模型、不使用 API key，不能当作完整业务流程测试。

## 2026-10-21：Windows 缺少 Python 时自动准备
