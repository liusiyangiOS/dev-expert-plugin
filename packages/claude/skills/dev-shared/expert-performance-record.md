# 轻量性能记录模板

按实际指标填入既有任务记录；未知写缺口，未运行写 `not_run`，不适用写理由。记录原始文件/查询定位，避免复制凭据、用户数据或完整日志。具体方法见 [性能协议](expert-performance.md)。

```text
需求/路径ID：
业务操作、成功条件与正确性证据：
目标、单位与来源（探索/验收）：
基线选择依据；前/后源码快照及相关脏文件指纹：
实际运行身份；已核实层级/未核实项：
环境/硬件/运行时/依赖/电源与资源限制/背景负载/网络：
数据集身份、大小/分布/种子：
工具/版本、实际命令或步骤、cwd、时间、退出状态：
计时起止/层级、单位；负载/并发/到达率/时长：
冷启动/预热、缓存、超时/重试、重复次数与样本单位：
原始记录定位（前/后每轮；含错误/超时/离群/缺失）：
汇总指标、样本量、分位数算法/适用性与噪声限制：
可比性检查/偏差与影响：
正确性、错误率、CPU/内存/IO等已定护栏：
变化（仅可比时）、目标是否满足、护栏是否通过：
PERF=improved|not_improved|not_comparable|insufficient_evidence
结论/未测/限制；外层ROUTE/GATE或VERDICT：
owner；独立验收者；复验条件/下一步：
```
